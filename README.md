# Проект банковского приложения
## Описание:
Проект веб-приложения для интернет-магазина
## Установка
1. Клонируйте репозиторий
`git clone https://github.com/stepanbaidakov/course_work_1.git`
2. Установите зависимости:
`pip install -r requirements.txt`
## Использование
1. Откройте файл `manage.py`
2. Запустите функцию `python manage.py runserver`
